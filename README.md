# Overview

Welcome to the **Salesforce Consumer Goods Cloud (CG Cloud) & Trade Promotion Management (TPM)** Corporate Training Repository.

This repository contains comprehensive training materials, hands-on labs, demonstrations, dashboards, capstone projects, mini projects, assessments, and implementation case studies designed for enterprise learners, Salesforce consultants, administrators, developers, solution architects, and business users.

The content follows a structured learning approach covering both functional and implementation aspects of Salesforce Consumer Goods Cloud.
